# Whospost Chrome MVP（尚未上架）

在獨立 Chrome 測試 profile 以「載入未封裝項目」選本資料夾。只需 storage；不讀 cookie、不捲動、不向 Threads 發請求。只在貼文頁處理其他作者的已載入回覆。首頁回覆串辨識尚未啟用，避免誤改主貼文。

- 預設：3 項淡化，選折疊模式時 4 項折疊；0／未知不改回覆。
- 為什麼卡：逐項依據、資料不足、分享證據、申訴／刪除、永久顯示。
- 「查詢」只是導向網站預填，沒有 POST scan。
- 本機 bucket 快取一小時、安裝標記持久保存；API 失敗仍可看原文。
- 永久顯示先落本機；申訴失敗顯示未送達，不冒充成功。
- 遙測未實作，也不送出任何遙測。設定變更重繪卡片，不重新整理使用者頁面。

伺服器：`WHOSPOST_LIST_ENABLED=1` 才開 API；`WHOSPOST_EXTENSION_IDS` 逗號分隔的確切 ID 才接受申訴。開發版也必須列出 ID，避免任何其他擴充功能冒用。上線前先批准清單公開／授權及隱私政策，確認刪除流程、審核分級與申訴治理；本輪不註冊付費帳號、不上架、不部署 API。

尚未實作：首頁 feed 回覆串、每日匯出更新、手動 review tier、遙測及 Web Store listing／icon／截圖包。實際 Threads DOM 改版仍需實頁驗證；合成 DOM 通過不代表正式相容。
