# 0.2 使用流程截圖（整套）

2026-10-24 拍，照使用順序排。這一組取代 #66 的 01–08 和 #65 先前的 `screenshots-block/`（兩組都併進來了）。1–10 是 10-24 晚上照 Felix 標的六處微調重拍的（commit `e7689c7`；第 2 點用修正版：名字旁只放原因晶片＋國旗）。

每張的「來源」只有三種寫法：

- **真 threads.com 登入頁面驗過**：Felix 本機已登入的 Chrome，英文介面、淺色模式，視窗 1458×787。
  - 真的部分：
    - Threads 頁面本身和登入狀態。
    - 擴充套件的畫面程式，也就是 `lib/engine.mjs`、`content.css`，和套件裡是同一份。
    - 帳號背景的兩個 Threads 請求，以及讀回來的加入年月和所在地點。
  - 模擬的部分：
    - Whospost 清單：四個帳號，分別 4、3、1、2 項符合，其中 1 項那個帶一段假的 AI 摘要。
    - 即時查的回應：查詢中 → 快篩 2 項 → 完整 4 項。
    - 沒有送任何請求到 Whospost。
  - 怎麼跑的：擴充套件**不是**從 chrome://extensions 安裝，是用截圖工具把 engine 打包後注入頁面：
    - storage 換成記憶體版。
    - 帳號背景的節流（2 秒一次、每小時 60 次）和自動暫停，用同一份 `lib/profile.mjs` 重建。
    - `window.open` 換成空函式，所以按「封鎖 @xx」不會開分頁，只會進冷卻。
    - 截圖工具在 session 的暫存資料夾，沒有進 repo。
- **fixture／模擬**：`node tests/extension/e2e/run.mjs --fixture` 跑出來的。
  - Playwright 的 Chromium 真的載入了 `extension/`。
  - 頁面是存下來的 Threads 頁，或照 10-24 實測結構手寫的 `tests/extension/e2e/fixture/profile.html`。
  - 擴充套件的行為是真的，Threads 的頁面是假的。
- **未驗證**：見最後一節。

**遮蔽**：所有帳號名稱換成 user01、user02…（同一個帳號在這組裡一直是同一個代號，浮層、按鈕、提示裡的名字也換掉；代號照頁面上出現的順序編，這次留言串多了新回覆，所以跟前一版的代號不同）。頭像換成灰色，右側欄「Quotes」的名字和內文模糊處理。貼文作者 zuck 是公開人物，沒有遮；留言內文是公開內容，保留原文。

## 沒拍到、未驗證的

- **用安裝好的擴充套件在登入頁跑完整流程**：未驗證。1–10 是注入同一份 engine 拍的，11–13 是注入 `lib/block.mjs` 拍的。安裝路徑由 CI 的 fixture e2e 驗：Playwright 載入 `extension/`，跑在 threads.com 網址下的 fixture 頁。
- **真站上「按下 → 開新分頁 → 新分頁接手」的銜接**：未驗證。10 的開分頁被攔下，11 是另外注入的；銜接只在 fixture e2e 斷言（交接資料 30 秒、只用一次、手動打開個人頁不會動作）。
- **按「復原」之後的畫面**：沒有另外截。結果和 1 一樣收回成一列，由 fixture e2e 斷言。
- **滑過名字時出現的「即時查」按鈕**：沒有截圖。滑過名字也會跳出 Threads 自己的名字卡片，上面是對方的真實顯示名稱、自介和粉絲數，不適合放進 repo。5 就是按了它之後的畫面。
- **「新帳號」灰標、「帳號背景暫停」pill、即時查失敗與每小時上限**：真實頁上沒有符合條件的帳號，也不能叫 Threads 真的拒絕，所以未在真實頁驗證；fixture e2e 有斷言。
- **真站上的失敗畫面（14）**：真的 Threads 選單沒壞，沒辦法在真站重現；邏輯在單元測試與 fixture 驗過。
- **真站上的彈出視窗（15）**：注入方式拍不到擴充套件的彈出視窗，只有 fixture。
- **中文介面**：真站只在英文介面驗過；中文的「封鎖／解除封鎖」字樣來自參考腳本 threads-report-block，沒在中文介面實測。
- **深色模式、手機寬度**：這組沒截。
- **AI 摘要 200 字上限的排版**：2 用的是 87 字的假摘要，接近 200 字時浮層高度沒在真站看過。
- **對照表外的地點**：真站這次只讀到羅馬尼亞、法國、台灣，都在表裡；對不到時顯示原文字的樣子只在單元測試驗過。
- **Windows 上的國旗**：Windows 的 Chrome 不畫國旗 emoji，會顯示成兩個字母（例如 RO）；這組是 macOS 拍的。
