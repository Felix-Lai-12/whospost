# 擴充功能隱私補充草稿（尚未發布）

Whospost 擴充功能只處理你正在看的 Threads 頁面已載入的回覆，不自行捲動、不抓其他貼文、不讀 cookie。它把公開帳號名稱轉成 SHA-256，只送出前四個十六進位字元，取得同 bucket 的公開行為線索後在本機比對。hash 前綴不是保證匿名；公開帳號仍可能被字典比對推測。

回覆文字、貼文文字、你的 Threads 帳號及瀏覽歷史不會由擴充功能上傳。所有 Whospost 請求都使用 credentials: omit。網路託管仍會接收到連線 IP；應用程式不把原始 IP 寫入名單或申訴表。

當你按「這不是網軍 · 永久顯示」，擴充功能先在本機保存此標記，再送出該帳號的完整 hash 與隨機安裝 ID 的加鹽 hash，作為去重的申訴回報。它不會直接改分數。回報失敗會顯示未送達，但本機永久顯示仍有效。

本機保存設定、永久顯示標記、一小時 bucket 快取、隨機安裝 ID。這版沒有遙測、不含廣告或分析工具。「用 Whospost 查」只開啟帳號預填頁面，仍由你按查詢。

清單只提供取回公開樣本的行為描述，不判定任何人的身分。你可以經正式站 /privacy#deletion 的既有入口申訴或要求刪除。公開清單授權、申訴保存期間及刪除流程須在啟用 API 前確認並同步正式隱私頁。
