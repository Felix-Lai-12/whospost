# Chrome Web Store 文案草稿（尚未送審）

名稱：Whospost 留言線索

簡短說明：在 Threads 回覆旁查看可核對的行為線索，保留原文與你的選擇。

完整說明：
Whospost 會在你已載入的 Threads 貼文回覆旁顯示公開查詢結果。展開「為什麼」可看命中的規則、資料不足項目與完整證據；你也能永久顯示回覆、提出申訴或要求刪除。沒有已存結果的帳號只提供查詢入口，是否查詢由你決定。

分數是尚未校準的行為線索，不是身分判定。粉絲、客服、朋友互動都可能符合；沒有命中也不代表正常。

權限說明：storage 用於設定、快取與本機標記；Threads host 用於已載入回覆的呈現；Whospost host 用於公開 hash bucket 查詢與使用者主動申訴。沒有 tabs、history、webRequest 或 scripting 權限，不讀 cookie，不下載遠端程式碼。

送審前未完成：正式隱私頁補充、確切 extension ID 與 API 開啟批准、128px icon、商店截圖、開發者帳號及最終審查。沒有建立或付款。
