# 商店截圖（0.1.0 送審版）

2026-10-27 重拍。原因：10-26 那批還寫「即時查」和「封鎖 @帳號」，與 0.1.0 不符。版面照 10-26 Felix 定案的設計：只標籤、不收起；原因晶片 ≥3 項淡紅、1–2 項淡黃、0 項淡綠「暫無疑慮」；沒查過的帳號旁常駐「AI 打詐」；浮層標題只寫 @帳號；彈出視窗是三格儀表板（AI 打詐／查詢背景／封鎖）＋這小時用量。四張都是 1280×800、24 位元 PNG、無透明，順序就是商店顯示的順序。

## 怎麼拍的

- 頁面：threads.com 上 @zuck 的公開貼文串，用 Felix 已登入 Threads 的 Playwright Chromium 設定檔開，英文介面、淺色模式。只讀頁面，沒有對帳號做任何操作。
- 擴充套件：Playwright 載入本 repo 的 `extension/`（和送審 zip 同一份程式），設定 `mode:'label'`。API 指向本機假站：health 開封鎖開關、AI 打詐一律回「查詢中」，不送任何請求到 Whospost。清單直接寫進 storage。
- 視窗 1195×747、裝置縮放 1280/1195，輸出就是 1280×800。Threads 右側欄（引用者、推薦帳號）藏起來，不放真實帳號的頭像與內文。
- 遮蔽：頁上帳號換成 user02、user03…，頭像換灰；貼文作者 zuck 是公開人物沒遮。
- 拍攝腳本放 session 暫存資料夾，沒有進 repo（`scripts/store-screenshots.mjs` 走登出頁，拍不出帳號背景，這次沒用）。
