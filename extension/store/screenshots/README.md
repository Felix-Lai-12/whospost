# 商店截圖（0.1.0 送審版）

2026-10-26 拍。五張都是 1280×800、24 位元 PNG、無透明，順序就是商店顯示的順序。

## 怎麼拍的

- 頁面：threads.com 上 @zuck 的公開貼文串，用 Felix 本機**已登入**的 Chrome 開，英文介面、淺色模式。
- 擴充套件：沒有從 chrome://extensions 安裝。截圖工具把 `lib/engine.mjs`＋`content.css`（和套件裡同一份，含 #72 的 AI 來源修正）打包後注入頁面，storage 換成記憶體版。截圖工具在 session 暫存資料夾，沒有進 repo。
- 視窗是 1458×787，改不了大小。為了湊 1280×800（16:10），把 Threads 右側欄藏起來（也順便不放真實引用者的名字與內文），裁左邊 1259×787 再等比放大到 1280×800。代價是右下角「已收起 2 則 · 顯示全部」那顆不在畫面裡。
- 遮蔽：頁上帳號換成 user01、user02…，頭像換灰（收起列裡的小頭像也換），貼文作者 zuck 是公開人物沒遮。user10 那則回覆附的圖裡有別人的帳號名，整張模糊。Threads 自己的名字卡片（真名、自介）拍 03 時跳出來過，關掉才拍。
