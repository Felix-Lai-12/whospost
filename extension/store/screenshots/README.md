# 商店截圖（0.1.0 送審版）

2026-10-26 拍，照 Felix 當天定案的設計：只標籤、不收起；原因晶片淡紅（≥3 項）／淡黃（1–2 項）；即時查常駐在沒查過的帳號旁；浮層標題只寫 @帳號；彈出視窗是三格儀表板＋這小時用量。四張都是 1280×800、24 位元 PNG、無透明，順序就是商店顯示的順序。

## 怎麼拍的

- 頁面：threads.com 上 @zuck 的公開貼文串，用 Felix 本機**已登入**的 Chrome 開，英文介面、淺色模式。
- 擴充套件：沒有從 chrome://extensions 安裝。截圖工具把 `lib/engine.mjs`＋`content.css`（和套件裡同一份）打包後注入頁面，storage 換成記憶體版、設定用預設值（`mode:'label'`）。截圖工具在 session 暫存資料夾，沒有進 repo。
- 視窗是 1458×747，改不了大小。把 Threads 右側欄藏起來（也順便不放真實引用者的名字與內文），裁左邊 1195×747（16:10）再等比放大到 1280×800。
- 遮蔽：頁上帳號換成 user01、user02…，頭像換灰，貼文作者 zuck 是公開人物沒遮。引擎會一直重畫浮層與提示列、把遮好的帳號名換回原名，所以 02 的浮層是遮完後的靜態複本。Threads 自己的名字卡片拍 03 時跳出來過，藏掉才拍。
